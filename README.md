## 🚀 Instalación Rápida

### 📱 En Termux (Android)

```bash
# Actualizar paquetes
pkg update && pkg upgrade -y

# Instalar dependencias
pkg install python git -y

# Clonar repositorio
git clone https://github.com/lopezdavison7-ops/Bot-Mini-Aura.git
cd Bot-Mini-Aura

# Dar permisos de ejecución
chmod +x deploy/start.sh

# Iniciar bot
./deploy/start.sh
